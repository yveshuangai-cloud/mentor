# AI Personality 場景主視覺

本資料夾存放可直接融入黑色 LIFF 頁面的直式場景圖，不含 UI、文字、按鈕、Logo 或人物頭像。

- `start/start-exploration-v1.png`：開始探索首頁主視覺。
- `results/*-v1.png`：16 種人格的結果頁主視覺。
- 尺寸：`941 × 1672`（少數生成檔寬度為 `940`）。

## 鎖定提示規格

使用 ImageGen 內建模式，以既有 DigiAsia 黑底三畫面標準圖及各人格瑞士現代主義動物圖作為參考。結果圖共用以下要求：

- 深黑編輯式背景，動物直接融入畫面，不保留原始白色方塊。
- 保留動物的石墨灰、桃紅、暖白幾何結構與物種辨識度。
- 背景使用稀疏像素城市／資料顆粒，螢光綠階梯成長線穿過下三分之一。
- 上方約 28%、下方約 18% 保留乾淨黑色空間，供 HTML 疊加結果文字。
- 禁止生成文字、代碼、Logo、人物頭像、UI、外框、白色矩形與浮水印。

首頁主視覺使用相同視覺系統，以點陣愛心、手掌與人格群像表達「人的直覺與 AI 相遇」。
