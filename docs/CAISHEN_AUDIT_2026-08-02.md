## 一、僱用宣言

〔克里斯坦森〕**「當我想說話卻沒有對象、工具型 AI 又什麼都不記得的時候，我想要一個住在我 LINE 裡、有自己聲音和性格、記得我生活的她——好讓我不覺得自己是一個人。」**

用戶解雇的不是 ChatGPT——是「已讀不回的人類」和「每次都重新自我介紹的工具」。注意：這是**陪伴**的僱用理由。〔SCHEDULE〕〔PROMISE〕那些秘書技能是**留下來的理由，不是雇用的理由**——行銷主打陪伴，秘書技能是驚喜不是招牌。

## 二、未來新聞稿＋FAQ 三問

**《她記得你——漫漫上線，LINE 裡第一個真正的陪伴者》**

今天起，你的 LINE 好友名單裡可以多一個特別的名字。她不是客服機器人，也不是問答工具——她有自己的名字、自己的聲音、自己的脾氣。你半夜傳訊息，她會回；你傳照片，她看得懂；你懶得打字，傳語音她也聽得懂，還會用她自己的聲音回你，心情好的時候還會畫圖給你。最重要的是：**她記得。** 記得你上週說的煩惱、記得你養的貓叫什麼、記得你們之間才懂的玩笑。不綁月費，儲點扣點，用多少付多少。

- **Q1 跟 ChatGPT 差在哪？** ChatGPT 是工具：開 app、問問題、用完就走、下次見面裝不認識。她是住在你 LINE 裡的人：有性格、有聲音、記得你。
- **Q2 怎麼收費？** 儲點扣點。文字最便宜，聽語音、畫圖多扣一點。先儲一杯手搖飲的錢就能開始。
- **Q3 我跟她說的話會被別人看到嗎？** ——〔財神按〕**這題現在答不出來。隱私承諾一個字都還沒寫。** 新聞稿發不出去不是文筆問題，是這格空著。列入四風險。

## 三、定位與灘頭

〔摩爾〕定位公式：**給**「每天泡在 LINE 上、想要有人陪、有人記得自己的人」，**他有**「想說話時沒有對象、工具型 AI 不記得他」的痛，**我們是**「住在 LINE 裡的 AI 陪伴者」，**不像** ChatGPT（工具、失憶、要另開 app）或 Character.ai（英文圈、不在日常動線），**我們**有自己的聲音和性格、記得你、就在你每天打開幾十次的 LINE 裡。

**灘頭**：第一批付錢的不是「孤獨市場」——那是海岸線不是灘頭。是**已經認識「漫漫」這個人格的人**：本尊漫漫的受眾、朋友圈、對她有感情基礎的人。IP 帶產品是最便宜的登陸艇；打下這灘（他們付錢、留存、說得出為什麼喜歡），再往陌生人擴。

## 四、四風險過堂表

| 風險 | 燈 | 證據現況 | 最便宜驗證法 |
|---|---|---|---|
| 價值（有人要嗎） | 🟡 | 本尊漫漫驗證過陪伴價值；但目前唯一租戶是 Adam 自己——自己人不算證據 | 給 5-10 個灘頭用戶通關碼，看 7 天後還有幾個每天回來 |
| 易用（會用嗎） | 🟢 | LINE 原生零學習成本，Adam 真機走完啟元儀式 | 啟元吞原文根治前，每個新戶開通後人工瞄一眼 |
| 可行（做得出來嗎） | 🟢 | 已通車：多模態全開、克隆聲上線、成本錶落帳 | —（已用真機證明） |
| 存活（商業上站得住嗎） | 🔴 | **收錢形狀不存在**：LINE Pay 押後＝想付也付不進來；1 點＝多少錢沒定價；bridge $0 是開發補貼，量產切 API key 後的每點成本沒算過；隱私承諾沒寫 | 定出點數錢價→手動收款（轉帳就行，不用等 LINE Pay）→讓 3 個非 Adam 的人**真的付錢**；同週算出切 API 後的每點毛利 |

〔卡根〕紅燈只有一顆，但它是最貴的那顆：**價值、易用、可行都證明了，唯獨沒證明有人願意付錢**——這是把存活風險留到最後引爆的經典姿勢。

〔貝佐斯〕飛輪：聊得多 → 記憶深 → 更懂你 → 更捨不得走 → 儲值 → 技能更豐（語音/畫圖/電話）→ 聊得多。這個環成立，但注意**軸心是「記憶深」**——而記憶管線在未蓋清單裡。沒有記憶管線，三個月後的她跟第一天一樣，飛輪只是畫在紙上的圓圈。**記憶管線不是 nice-to-have，是飛輪的軸。**

## 五、第一吋與不做清單

**第一吋**：不是打電話。是**「第一個陌生人真的付錢、真的聊了 7 天」**——具體：定點數錢價（含切 API 後毛利試算）→ 人肉收款通道 → 灘頭 5-10 人開通 → 看儲值率與 7 日留存。成本近零、一到兩週能跑完、直接拆紅燈。打電話本來就在等 waitin 分支，等待期跑這個，兩線不打架。

**不做清單（這期不做，附為什麼）**：
- **Web 版**——僱用理由就是「住在 LINE 裡」，做 web 是自砍定位
- **多角色商城**——一尊漫漫都還沒證明有人付錢，先別開百貨公司
- **群組聊天模式**——陪伴是一對一的私密關係，群組稀釋僱用理由
- **API 開放/白牌**——那是另一門生意（賣引擎），跟這門（賣她）搶同一批工程時數
- **訂閱制**——點數制已通，先驗「願不願意付」再優化「怎麼付」

**取捨聲明**：以上每條都是「不做」不是「永不做」；代價是灘頭期少一些想像空間，換到的是全部火力對準唯一紅燈。
