# AIEQ 幾何動物人格視覺系統

系統版本：`AIEQ-GEOMETRIC-ANIMAL-v3`
狀態：方向 A「瑞士現代主義動物徽記」已選定；完整 16 型首版 PNG 素材、總覽圖與素材索引已完成。既有手工 SVG 僅作資訊架構草圖，不作美術定稿。

## 1. 核心決策

AIEQ 維持 16 種動物人格。抽象化只改變畫法，不移除動物：每一型以一隻可辨認的動物作核心，再以簡潔幾何輪廓、粉紅與灰色建立一致的品牌系統。

```text
16 型 = 16 個四字母代碼 = 16 隻幾何動物
```

每張卡必須同時具備：

1. 左上角固定的完整四字母代碼。
2. 中央可辨認物種的幾何動物圖騰。
3. 粉紅、灰色與白色負空間。

## 3. 色彩

- AIEQ Pink：`#E85D87`
- AIEQ Gray：`#55565C`
- White：`#FFFFFF`，只作負空間

所有動物都使用同一組色彩，不以顏色區分族群或能力。允許粉紅與灰使用透明度建立層次，不加入第三品牌色、漸層、陰影或發光。

## 4. 動物幾何化規則

- 先保留物種剪影，再刪除不影響辨識的細節。
- 使用圓、橢圓、圓角矩形、三角形與少量貝茲曲線。
- 每隻動物至少保留兩個專屬辨識特徵。
- 線寬、眼睛大小、卡片留白與圖騰尺度一致。
- 動物可以是正面頭像或側面剪影，以最容易辨認物種為準。
- 不追求真實毛髮、羽毛與皮膚紋理。
- 不使用人類衣服、皇冠、盔甲、職業道具或戰力符號。
- 不把動物做成幼獸、貼圖或大頭 Q 版。

## 5. 卡片版面

- 正方形 1:1。
- 四字母代碼固定在左上角，距離左、上各 8%。
- 代碼固定使用灰色、大寫、粗體幾何無襯線字。
- 中央動物占卡片寬高約 56%～62%。
- 動物圖騰視覺中心略低於卡片中心，不能遮到代碼。
- 卡片使用細灰框與 8% 安全留白。
- 不在原圖加入人格說明、分數、按鈕或動物名稱。

## 6. LINE 與 LIFF

- LINE 結果卡顯示單一動物圖騰；名稱、信心與按鈕放在 Flex body。
- LINE 的 16 型總覽拆成兩組八張或四組四張。
- LIFF 桌面版使用 4 × 4，手機版使用兩欄 grid。
- 好友頭像可以只裁中央動物；四字母代碼在頭像旁由 HTML 顯示。
- SVG 是母版，另外輸出 1040、512、192 像素 WebP／PNG。

## 7. 驗收條件

1. 遮住四字母代碼後，仍能辨認大多數動物物種。
2. 16 隻動物全部存在，不以純抽象符號取代。
3. 四字母代碼完全正確並固定左上角。
4. 只使用粉紅、灰與白色負空間。
5. 16 張卡看起來像同一套圖標，而不是不同插畫風格。
6. 在 96 × 96 像素仍保留主要物種輪廓。
7. 圖像不暗示人格高低、稀有度或能力排名。
8. 動物只負責辨識與敘事，不參與 AIEQ 計分。
