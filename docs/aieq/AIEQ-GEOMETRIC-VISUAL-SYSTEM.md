# AIEQ 抽象幾何人格視覺系統

系統版本：`AIEQ-GEOMETRIC-v2`
狀態：**已由 `AIEQ-GEOMETRIC-ANIMAL-v3` 取代。** 此版誤將動物完全抽離，僅保留為幾何語法探索。
參考圖角色：只作版面密度與 4 × 4 類型總覽參考，不直接複製其配色或文字內容

## 1. 核心決策

AIEQ 保留四組人格偏好的 16 種組合，但不再用具象動物肖像作為主要識別。每一型使用一個可解釋的抽象幾何圖騰，讓圖案本身由 E／I、S／N、T／F、J／P 四個偏好共同生成。

總數固定為：

```text
2 × 2 × 2 × 2 = 16 型
```

每張卡左上角固定放完整四字母代碼，例如 `ISTJ`。不會同時放 E、I、S、N、T、F、J、P 八個字母。

## 2. 色彩

只使用兩個品牌色，白色作負空間：

- AIEQ Pink：`#E85D87`
- AIEQ Gray：`#55565C`
- Negative Space：`#FFFFFF`，不視為第三個品牌色

允許同一品牌色使用 18%、35%、60%、100% 不透明度建立層次，不增加紫色、藍色、綠色或漸層。

規則：

- 四字母代碼固定使用灰色。
- 主要人格動勢使用粉紅色。
- 結構線、定位點與卡片細框使用灰色。
- 不以顏色區分人格高低、族群或能力分數。

## 3. 四組偏好的幾何語法

| 偏好 | 幾何語法 | 視覺意義 |
| --- | --- | --- |
| E | 中心向外放射、外部節點 | 能量透過外界互動展開 |
| I | 同心、內聚、中心核心 | 能量先在內部整理 |
| S | 方形、格點、等距排列 | 具體資訊與可確認步驟 |
| N | 曲線、跳接、非線性連結 | 模式、可能性與跨點連結 |
| T | 稜角、直線、軸線與對稱 | 原則拆解與邏輯判準 |
| F | 圓弧、包覆、相接圓形 | 價值感受與關係影響 |
| J | 封閉外框、完成形、對齊 | 收斂、結構與明確完成 |
| P | 開口、位移、未完成軌跡 | 探索、回饋與保留選項 |

圖騰不是測驗分數。它只把已確認的四字母結果轉譯成視覺符號。

## 4. 圖騰組成

每一個圖騰固定由四層疊合：

1. **能量核心層**：E 或 I。
2. **資訊路徑層**：S 或 N。
3. **決策輪廓層**：T 或 F。
4. **行動邊界層**：J 或 P。

四層必須共用中心點、線寬與留白比例。圖形要像一個完整符號，不像四個 icon 硬疊在一起。

## 5. 卡片版面

- 母版比例：1:1。
- 四字母代碼固定在左上角，距左、上各 8%。
- 代碼使用大寫、粗體、幾何無襯線字；不得使用裝飾字或彩色陰影。
- 代碼寬度不超過卡片的 34%，不得與中央圖騰重疊。
- 中央圖騰占卡片寬高約 58%，視覺中心略低於幾何中心。
- 卡片四周保留至少 8% 安全區。
- LINE 縮圖中，先看見四字母代碼，再看見圖騰。
- 原始人格圖騰不包含說明文字；名稱、摘要與按鈕由 Flex 或 LIFF 排版。

## 7. LINE 與 LIFF

### LINE 結果卡

- 使用單一 1:1 圖騰卡作為 hero。
- 左上角完整顯示四字母代碼。
- 卡片 body 顯示 AIEQ 名稱、信心與一句行為摘要。
- 「確認這是我」與「完整分析」放在圖片之外，避免圖檔含可點擊假按鈕。

### 16 型總覽

- LINE Flex 一個 carousel 最多 12 個 bubble，因此分成兩組八張或四組四張。
- LIFF 使用 4 × 4 grid；手機版使用 2 欄，點擊後開啟詳細頁。
- 好友列表可將圖騰裁成圓形，但四字母代碼應獨立放在頭像旁，不一起裁掉。

## 8. 技術實作

圖騰應以 SVG、Canvas 或程式化元件生成，不使用生圖模型直接產生最終字母與幾何：

- 字母可保證完全正確。
- 16 型可以共用同一套四層幾何元件。
- LINE、LIFF、分享圖與深淺模式可重複輸出。
- 未來更換粉紅或灰色，只需改 design token。
- 每個圖騰可經自動測試確認四個偏好層都存在。

建議元件介面：

```ts
<AieqGlyph type="INTP" size={512} showCode />
```

## 9. 禁止事項

- 不再以具象動物作主要圖案。
- 不加入第三個品牌色、彩虹分類或每型不同底色。
- 不使用漸層、發光、玻璃擬態、陰影或金屬質感。
- 不使用大段人格文案壓在圖片裡。
- 不讓四字母代碼更換位置、大小規則或字體風格。
- 不把 T 畫得比較尖銳危險，或把 F 畫得比較柔弱可愛。
- 不把 J 畫得完整精緻、P 畫得像未完成稿；兩者完成度必須相同。
- 不將圖騰當成 AIEQ 六項能力分數或排名。

## 10. 驗收條件

1. 16 張卡的四字母代碼都正確且固定在左上角。
2. 全系列只使用粉紅、灰與白色負空間。
3. 同一字母在所有圖騰中使用相同幾何語法。
4. 任兩種類型的圖騰都能從偏好層找到可解釋差異。
5. 在 96 × 96 像素仍能看清代碼與主要輪廓。
6. 圓形好友頭像裁切後仍能辨認中央圖騰。
7. 所有類型具有相同線寬、視覺重量與完成度。
8. 不出現能力高低、稀有度或戰力暗示。
