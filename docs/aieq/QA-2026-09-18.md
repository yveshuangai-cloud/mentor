## 2. 線上 staging（通過，有觀察）

端點全部 200：`/health`、`/aieq`（34 KB）、manifest、service worker（含 `service-worker-allowed`）、`/api/aieq/config`（`demoMode:false`、正確 LIFF ID 與 OA ID）、PWA icon 三種、場景圖、分享卡、動物圖。

安全行為：

| 測試 | 期望 | 結果 |
|---|---|---|
| production 使用 demo token | 拒絕 | 401 |
| 無 token／亂數 token | 拒絕 | 401 |
| webhook 無簽章／錯簽章 | 拒絕 | 403 |
| LINE 官方 Verify（正確簽章） | 接受 | 200（伺服器紀錄兩次） |
| 刪除資料未附確認字 | 拒絕 | 400 |
| `/api/admin/*` 無 token | 拒絕 | 401 |

伺服器紀錄（最近一段）：0 ERROR、0 WARN、0 個 5xx。

一般瀏覽器開 `/aieq`：`liff.init` 成功並導向 `access.line.me` 的 LINE Login 頁，證明 LIFF ID 與 Login channel 設定有效（未登入，屬帳號操作）。

觀察（非阻塞）：

- **圖片偏大**：首頁場景 1.7 MB、結果場景 1.5 MB、分享卡 1.05 MB；一次遊玩約 4.2 MB。以 JPEG q85 重存可降約 73%（分享卡 1.05 MB → 282 KB）。手機行動網路下建議處理；`sips` 不支援 WebP，需另找工具或改用 JPEG。
- `/admin` 的靜態 HTML 不需 token 即可開啟（API 有擋）。屬饅頭平台既有行為，不在 AI 人格誌範圍。
- `/aieq` 未送 HSTS／X-Frame-Options／CSP 標頭。LIFF 在 LINE 內開啟不需 iframe，可考慮加 `X-Frame-Options: DENY` 與基本 CSP；屬強化項目。

## 4. 只能在真實 LINE 驗證（待威廷手機）

- [ ] 聊天室輸入「開始 AIEQ」收到第一題 Flex 卡；最長選項主標（15 字）未被截成「…」
- [ ] 傳「你好」只收到一則導引訊息（若兩則，代表官方帳號後台仍有自動回應開著）
- [ ] 已是好友者結果頁不再出現「加入好友」卡片（`liff.getFriendship()`）
