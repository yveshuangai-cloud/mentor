固定聲明：AIEQ 是參考四組人格偏好的 AI 時代行為傾向測評，非心理診斷，也不是官方 MBTI® 測驗。

重要結論：八題沒有標準正確答案。每個選項代表一種現實策略；正負號只表示偏好方向或當下能力證據，不表示好壞、階級或錄取標準。

## 0. 一頁讀懂：為什麼會有 16 型

16 型不是另外發明的 16 個分數，而是四組二元偏好的笛卡兒積：2 × 2 × 2 × 2 = 16。四個位置依序固定為 E/I、S/N、T/F、J/P。

真實行為情境

  ↓ 使用者選擇 A／B／C，或以自然語言對應到唯一選項

AnswerEvent（答案事件；附解讀信心）

  ↓ 選項中的 evidence 權重 × interpretationConfidence

四組偏好 balance：EI、SN、TF、JP

  ↓ 各軸依方向選出 1 個字母

四字母代碼（例如 INTP）

  ↓ 只做結果視覺映射，不回頭改分

16 種動物圖騰

同一批答案 ──另一路──→ 六項 AIEQ 可發展能力 → 成長報告

不可逆護欄：動物不參與計分；人格代碼不推導 AI 能力；六項能力也不反推人格。只有使用者確認後的 canonical profile 才能成為朋友圈可見結果。

## 1. 四組人格偏好：代碼生成規則

現行程式以有號 evidence 累積。下列「負向／正向」是數學方向，不是價值判斷。

### EI：互動取向／內在加工取向

- 負向 evidence → E：傾向透過互動、召集、交換與外部回饋推進。

- 正向 evidence → I：傾向先獨立研究、內在整理、完成原型後再分享。

- 證據題：Q3 團隊試作、Q7 學習新模型。

### SN：具體經驗／模式可能性取向

- 負向 evidence → S：傾向從操作資料、具體步驟、可觀察錯誤開始。

- 正向 evidence → N：傾向從小實驗、整體模式、替代架構與可能性開始。

- 證據題：Q1 導入新工具、Q5 自動化失敗。

### TF：原則分析／人際價值取向

- 負向 evidence → T：傾向使用資料、邏輯、測試標準與風險門檻決策。

- 正向 evidence → F：傾向先理解人的影響、顧慮、情境與共同接受度。

- 證據題：Q2 重要 AI 輸出、Q6 團隊意見分歧。

### JP：結構收斂／彈性探索取向

- 負向 evidence → J：傾向先定義範圍、重排行程、責任與檢查點。

- 正向 evidence → P：傾向先做版本、試替代路線、用回饋逐步收斂。

- 證據題：Q4 流程失效、Q8 模糊任務。

## 2. 六項 AIEQ 能力：與人格分開計算

- AI 協作：能否把 AI、人、情境與共同決策接起來。

- 轉型速度：面對工具或流程改變時，能否快速採取下一步。

- 模糊容忍：資訊不完整時，能否在風險可控下繼續探索。

- 主動性：是否主動定義問題、試作、求證或推進。

- 驗證能力：是否回到來源、標準、風險與可觀察證據。

- 持續學習：是否把失敗、碎片資料與實作整理成可重用知識。

能力分數為 0–100 的當下行為證據，不是固定天賦，也不能拿來宣稱某人格優於另一人格。同一個 INTP、ESFJ 或任何代碼，都可能有完全不同的六項能力輪廓。

## 3. 八題正式題庫、答案選項與實際計分

符號說明：EI／SN／TF／JP 為四組偏好；協作＝AI 協作；轉速＝轉型速度；模糊＝模糊容忍；主動＝主動性；驗證＝驗證能力；學習＝持續學習。數值範圍為 -1～1。未列出的維度代表該選項不提供該維度證據。

「direct／reverse／cross_check」是題庫的驗證角色：direct 為主要情境證據；reverse 用不同選項排序或相反風險檢查作答慣性；cross_check 用另一種場景交叉驗證同一偏好。

### Q1｜q01_new_tool｜direct

情境：公司下週要導入一套你沒用過的 AI 工具。

問題：你最可能先做什麼？

- A 先做小實驗｜直接拿一個低風險工作做小實驗，再依結果調整。計分：SN +0.70、轉速 +1.00、模糊 +0.70、主動 +0.80。

- B 先看操作資料｜先讀完操作說明與案例，確認流程後再開始。計分：SN -0.80、轉速 -0.25、模糊 -0.50、學習 +0.50。

- C 先問清楚目標｜先找主管或同事確認導入目標與成功標準。計分：SN -0.20、協作 +0.60、驗證 +0.60、主動 +0.35。

因果判讀：此題同時觀察「從具體資料或可能性試驗開始」以及面對新工具時的速度、模糊承受與主動行動。

### Q2｜q02_ai_output｜reverse

情境：AI 很快產出一份看起來完整、但會影響客戶的重要分析。

問題：你會怎麼處理？

- A 先交再說｜格式完整就先交付，有問題再修正。計分：TF -0.10、驗證 -1.00、主動 -0.35。

- B 逐項查證｜抽出關鍵結論，回到資料來源逐項查證。計分：TF -0.80、驗證 +1.00、主動 +0.55。

- C 找人共同檢視｜請熟悉客戶情境的人一起檢視結論與風險。計分：TF +0.70、驗證 +0.75、協作 +0.80。

因果判讀：用高風險輸出區分原則查證與情境共審，並檢查使用者是否會對完整外觀產生過度信任。

### Q3｜q03_team_trial｜direct

情境：團隊想試用 AI 改善一個長期卡住的流程。

問題：你通常會扮演哪種角色？

- A 召集大家試做｜召集相關的人一起畫流程、分工試做。計分：EI -1.00、協作 +1.00、主動 +0.80。

- B 獨立做出原型｜先自己安靜研究並做出原型，再拿給團隊看。計分：EI +1.00、協作 +0.25、主動 +0.90。

- C 整理需求風險｜先整理每個人的需求與顧慮，形成共同問題。計分：EI -0.35、協作 +0.85、驗證 +0.40。

因果判讀：核心不是外向或內向的社交印象，而是遇到團隊問題時，先從外部互動或內在加工啟動。

### Q4｜q04_plan_breaks｜reverse

情境：期限剩兩天，原本規劃的 AI 工作流程突然不能用了。

問題：你的第一個反應通常是？

- A 重排行程與責任｜立刻重排工作、責任與檢查點，保住必要交付。計分：JP -1.00、轉速 +0.65、模糊 -0.25、主動 +0.70。

- B 試幾條替代路線｜快速試幾條替代路線，邊做邊決定採用哪條。計分：JP +1.00、轉速 +1.00、模糊 +0.90。

- C 先停下來等資訊｜先暫停，等工具恢復或有更完整資訊再決定。計分：JP -0.15、轉速 -0.90、模糊 -0.80、主動 -0.70。

因果判讀：在時間壓力下比較「先重建結構」與「先探索替代路徑」，並同步觀察停滯風險。

### Q5｜q05_failed_automation｜cross_check

情境：你做的自動化連續兩次失敗，而且原因不明。

問題：下一步你比較可能怎麼做？

- A 拆解實際步驟｜把流程拆小，逐步記錄輸入、輸出與錯誤。計分：SN -1.00、驗證 +1.00、學習 +0.70。

- B 換個架構重想｜退一步重想問題，也許應該換一種自動化架構。計分：SN +1.00、轉速 +0.60、模糊 +0.60、學習 +0.55。

- C 先改回人工｜先改回原本的人工方式，暫時不再投入。計分：SN -0.35、轉速 -0.55、學習 -0.80。

因果判讀：用失敗排查場景交叉驗證 S/N；A 是具體拆解，B 是模式重構，C 則主要提供退出與學習中斷的證據。

### Q6｜q06_team_disagrees｜cross_check

情境：團隊對「是否採用 AI 的建議」意見分成兩派。

問題：你最可能如何推進？

- A 先談人的顧慮｜先讓雙方說出擔心的影響，再找能共同接受的做法。計分：TF +1.00、協作 +1.00、驗證 +0.30。

- B 設共同測試標準｜先定義資料、指標與風險門檻，用小測試做決定。計分：TF -1.00、協作 +0.65、驗證 +1.00。

- C 交給權責者決定｜整理兩派意見，交由最終權責者直接決定。計分：TF -0.25、協作 -0.30、主動 -0.35。

因果判讀：以衝突場景交叉驗證 T/F；A 先處理人與影響，B 先建立原則與證據，兩者都可能是成熟策略。

### Q7｜q07_learning｜reverse

情境：出現一個可能改變你工作的全新 AI 模型，但教學資料很零散。

問題：你會如何開始理解它？

- A 等完整課程｜等有完整課程或公司安排訓練後再學。計分：EI +0.10、學習 -0.80、主動 -0.75。

- B 找同伴交換測試｜找幾個同伴各自測試，再交換發現與踩坑。計分：EI -1.00、學習 +0.90、協作 +1.00、主動 +0.55。

- C 自己建立筆記｜自己蒐集碎片資料、實作並整理成可重用筆記。計分：EI +1.00、學習 +1.00、主動 +0.80。

因果判讀：用學習啟動方式交叉驗證 E/I，並把「與人交換」和「獨立統整」都視為可形成高學習證據的不同路線。

### Q8｜q08_vague_request｜direct

情境：主管只說「用 AI 讓這件事更有效率」，沒有給明確標準。

問題：你通常怎麼接這個任務？

- A 先定義範圍｜列出目標、限制與驗收方式，確認後再執行。計分：JP -1.00、模糊 -0.25、主動 +0.65、驗證 +0.50。

- B 先做可看的版本｜根據現有線索先做一個可看的版本，用回饋縮小方向。計分：JP +1.00、模糊 +1.00、主動 +1.00、轉速 +0.75。

- C 等待更明確指示｜先處理其他工作，等收到更明確指示。計分：JP -0.25、模糊 -0.85、主動 -1.00。

因果判讀：直接比較先結構化與先試作的任務承接方式，並辨識等待造成的主動性與轉型速度缺口。

### 自然語言答案如何處理

- 卡片點擊與自由文字都必須先正規化成同一個 AnswerEvent。

- 自由文字只有在唯一匹配某一選項時才配分；無法可靠理解時保留原文、interpretationConfidence＝0，不猜答案。

- 「不確定／跳過」不配分，只降低 coverage 與信心；「回上一題」撤銷目前答案 projection，但保留事件稽核歷程。

- 同一 eventId 重送只處理一次，避免 LINE 重複點擊或 webhook 重送造成重複計分。

## 4. 交叉驗證矩陣：題目如何共同造成分類

人格偏好：

EI ← Q3（團隊角色，direct）＋ Q7（學習啟動，reverse）

SN ← Q1（新工具，direct）＋ Q5（失敗排查，cross_check）

TF ← Q2（重要輸出，reverse）＋ Q6（團隊分歧，cross_check）

JP ← Q4（流程失效，reverse）＋ Q8（模糊任務，direct）

AIEQ 能力覆蓋：

AI 協作 ← Q1、Q2、Q3、Q6、Q7

轉型速度 ← Q1、Q4、Q5、Q8

模糊容忍 ← Q1、Q4、Q5、Q8

主動性 ← Q1、Q2、Q3、Q4、Q6、Q7、Q8

驗證能力 ← Q1、Q2、Q3、Q5、Q6、Q8

持續學習 ← Q1、Q5、Q7

交叉驗證的目的不是要求兩題選得一模一樣，而是觀察同一偏好在不同場景是否保持方向。若方向分裂，應降低信心並寫成「跨情境表現不同」，而不是硬貼標籤。

## 5. 計分、信心與字母生成

### 5.1 單一維度分數

signedEvidence = Σ（選項 signal × 答案解讀信心）

observedWeight = Σ（|signal| × 答案解讀信心）

balance = signedEvidence ÷ observedWeight，限制於 -1～+1

displayScore = 50 + 50 × balance

interpretationConfidence 是「系統對輸入是否正確對應選項」的信心，不是人格確定度。卡片答案通常為 1；自然語言若不明確則降低，無法唯一對應時為 0。

### 5.2 覆蓋率與結果信心

availableWeight = 題庫中該維度每題最強選項的 |signal| 加總

coverage = observedWeight ÷ max（availableWeight × 0.7, 1），上限 1

interpretationCertainty = certaintyWeight ÷ rawWeight

directionalConsistency = 0.5 + 0.5 × |balance|

confidence = coverage × interpretationCertainty × directionalConsistency

overallConfidence = 四組偏好＋六項能力，共十個維度 confidence 的平均

### 5.3 四字母代碼

- EI：balance < 0 → E；balance ≥ 0 → I。

- SN：balance < 0 → S；balance ≥ 0 → N。

- TF：balance < 0 → T；balance ≥ 0 → F。

- JP：balance < 0 → J；balance ≥ 0 → P。

- 某軸完全沒有有效證據時顯示 X，不應進入正式 16 型確認。

### 5.4 需要企劃與測評共同裁決的現行邊界

現行程式在「有證據但 balance 剛好等於 0」時會選右側字母（I／N／F／P）。這是實作規則，不代表測量上真的確定。建議下一版增加中性區，例如 |balance| < 0.15 時先顯示 X 或進行一題確認題；門檻必須經樣本測試後決定，企劃不得單獨改權重。

目前 8 題是 Pilot 行為題庫，已具不同場景與正反／交叉設計，但尚不能宣稱心理計量驗證完成。正式對外前需做認知訪談、題項偏誤檢查、重測一致性與樣本分布分析。

## 6. 四軸如何組成 16 型，並映射動物

每一型只是四個偏好的組合。動物在結果確認後才出現，是記憶與分享用的視覺隱喻；不提供任何計分 evidence。

### ISTJ｜河狸｜I＋S＋T＋J

自然優勢：把混亂變成可靠系統。

容易忽略：可能太晚才接受新工具。

成長路線：用低風險試點替代一次到位。

### ISFJ｜企鵝｜I＋S＋F＋J

自然優勢：穩定照顧團隊與品質。

容易忽略：可能默默承擔過多轉型成本。

成長路線：把照顧化成可複製流程。

### INFJ｜大象｜I＋N＋F＋J

自然優勢：看見長期影響與人的需求。

容易忽略：可能為理想等待完美時機。

成長路線：用小型原型驗證願景。

### INTJ｜貓頭鷹｜I＋N＋T＋J

自然優勢：設計長期策略與架構。

容易忽略：可能低估導入所需的共識。

成長路線：讓利害關係人提早參與。

### ISTP｜貓｜I＋S＋T＋P

自然優勢：快速拆解工具與實際問題。

容易忽略：可能略過溝通與文件。

成長路線：把有效解法留下可重用紀錄。

### ISFP｜小熊貓｜I＋S＋F＋P

自然優勢：敏銳察覺體驗與價值衝突。

容易忽略：可能避開過度制度化的改變。

成長路線：為創作建立最小安全框架。

### INFP｜鹿｜I＋N＋F＋P

自然優勢：守住意義、倫理與人的可能。

容易忽略：可能在選項太多時延遲決定。

成長路線：設定期限並完成一次可逆實驗。

### INTP｜章魚｜I＋N＋T＋P

自然優勢：建立模型並探索多條解法。

容易忽略：可能一直研究而未交付。

成長路線：先交一個能被使用者否定的版本。

### ESTP｜獵豹｜E＋S＋T＋P

自然優勢：在變動中快速行動與修正。

容易忽略：可能低估驗證和治理。

成長路線：在速度流程中加入必要檢查點。

### ESFP｜鸚鵡｜E＋S＋F＋P

自然優勢：帶動參與並讓新工具容易接近。

容易忽略：可能追逐新鮮感而缺乏沉澱。

成長路線：每次實驗都留下成果與學習。

### ENFP｜水獺｜E＋N＋F＋P

自然優勢：連結創意、人與新機會。

容易忽略：可能同時展開太多方向。

成長路線：用一項衡量標準選出下一步。

### ENTP｜烏鴉｜E＋N＋T＋P

自然優勢：挑戰假設並組合新解法。

容易忽略：可能頻繁換題而未完成落地。

成長路線：替探索設定停止條件與交付點。

## 7. 因果說明圖：可交給設計與前端的元件規格

### 元件 A｜Scenario Card 情境卡

輸入：scenario＋prompt。輸出：一個可在 10 秒內理解的真實工作情境。必要狀態：預設、讀題中、已回答、無障礙朗讀。禁止：人格字母、動物提示、好壞暗示。

### 元件 B｜Answer Strategy 三選一策略卡

輸入：shortLabel＋完整 label。輸出：A/B/C 選擇事件。每張卡只呈現行動策略，不顯示分數。三個選項視覺權重一致，順序不得固定對應某一端。

### 元件 C｜Evidence Chip 證據晶片（內部／企劃檢查模式）

輸入：dimension、signal、validation。視覺：粉紅表示正向軸、灰色表示負向軸，旁邊必須標註「方向非好壞」。使用者正式答題介面不顯示，以免誘導。

### 元件 D｜Axis Causal Track 四軸因果軌

Q3 A（EI -1.0） ─┐

                  ├─ 加權累積 → EI balance -0.62 → E

Q7 B（EI -1.0） ─┘

必備資訊：來源題號、選項、權重、解讀信心、合計 balance、字母結果。可點開查看證據，但預設只顯示摘要。

### 元件 E｜Confidence Meter 信心尺

由 coverage、interpretation certainty、directional consistency 三段組成。不得只顯示一個神秘百分比；低信心文案固定使用「目前證據不足或跨情境表現不同」。

### 元件 F｜Code Composer 四字母組合器

四條軸各輸出一個字母，依 EI→SN→TF→JP 排序拼成代碼。若任何一軸為 X，顯示暫定代碼並要求補充證據，不直接揭示正式動物。

### 元件 G｜Animal Reveal 動物揭曉

輸入：已確認四字母代碼。輸出：動物圖、自然優勢、盲點、成長路線。動物圖不得出現在題目或計分流程中。所有 16 張卡同尺寸、同色盤、同資訊量，不做稀有度。

### 元件 H｜AIEQ Ability Profile 能力輪廓

與四字母代碼並列但不連線推導。建議以六條獨立刻度或雷達圖呈現，標示「可發展能力」，不要用戰力、等級、勝率或淘汰語言。

### 元件 I｜Confirmation Gate 結果確認閘

流程：completed_unconfirmed → 使用者查看證據與信心 → 確認並綁定 LINE ID → confirmed。只有 confirmed 才能成為朋友圈 canonical profile；第一版不提供自動重測入口。

### 視覺基準

- 主色：dusty rose pink #D95F82。

- 中性色：graphite gray #505158。

- 底色：warm white #F7F4F2。

- 字母代碼固定在左上安全區；動物居中略偏右下。

- 因果線只使用單向箭頭；禁止用皇冠、星級、戰力條或金銀銅暗示階級。

## 9. 企劃參與優化與調整：權限、流程、驗收

### 9.1 企劃可以調整

- 情境是否一眼可懂、是否貼近目標產業與日常工作。

- 三個選項是否都合理、是否存在一眼可見的社會期許答案。

- 結果名稱、標語、故事、合作建議與成長實驗是否自然、可分享。

- 動物象徵是否跨文化可接受、是否有羞辱或階級聯想。

- 低信心、暫定結果與確認流程的文案是否誠實且低摩擦。

### 9.2 企劃不可單獨調整

- 選項 evidence 的正負方向與數值權重。

- 人格軸與六項能力的關聯方式。

- 信心公式、中性區門檻、題目刪除或新增後的分數可比性。

- 以動物、分享率、熱門度或商業需求反推分類。

### 9.3 共同變更流程

企劃提出問題與改寫草案

  ↓

測評負責人標記受影響維度、方向與偏誤風險

  ↓

工程更新 instrumentVersion、權重與測試

  ↓

小樣本認知訪談＋選項分布檢查

  ↓

產品確認體驗與同意邊界

  ↓

共同簽核後發布；舊 session 保留原版本，不混算

### 9.4 每次題目調整的變更單欄位

- 題號／版本／提出角色。

- 原文、改寫文與改寫理由。

- 預期測量維度、各選項方向與權重。

- 可能的社會期許、產業偏誤、文化偏誤與無障礙風險。

- 自然語言 aliases 與模糊答案範例。

- 受影響的自動測試、樣本結果與核准人。

### 9.5 發布前驗收

- 每組人格偏好至少有兩個不同場景，且 validation 角色不完全相同。

- 重要 AIEQ 能力至少有三個證據點。

- 三個選項都像真實策略，沒有明顯正解。

- 卡片與唯一匹配的自然語言答案產生相同有效答案與分數。

- 不確定、跳過、回上一題、中斷續答與重複 eventId 均通過測試。

- 結果附信心與固定聲明；動物沒有寫入計分邏輯。

- 只有 confirmed canonical profile 進入朋友圈；不因重開頁面自動重測。
