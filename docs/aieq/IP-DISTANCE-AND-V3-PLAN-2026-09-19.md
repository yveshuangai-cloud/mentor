## 0. 一句話結論

**技術上完全可行，但換題庫本身不會降低 MBTI 智財風險。**

V3 的題目是原創的，我們現行的題目也是原創的，兩者都沒有抄襲 MBTI 題項，所以「換題」這個動作不影響著作權風險。真正的風險在**商標字樣**與**把四字母當成產品主identity**，而 V3 文件不但保留四字母，還在規格裡直接寫「四組人格偏好（MBTI 代碼）」，等於把關聯寫進文件。

YVES 哥的方向是對的（降低對 MBTI 的依賴），但他選的槓桿（重寫題目）不是能移動風險的那一根。真正有效的是下面的 A 軌。

> 本文件不是法律意見。四字母是否保留、免責文案怎麼寫，建議由協會法務最終確認。

## 2. 風險盤點

### 2.1 智財風險的真實位置

| 風險來源 | 現況 | 換成 V3 後 | 評估 |
|---|---|---|---|
| **題項著作權** | 題目為本專案原創 | V3 也是原創 | 本來就無風險，換題不改變 |
| **MBTI® 商標** | 3 處使用者可見文字出現「MBTI®」 | V3 沒處理 | **實際風險所在** |
| **四字母代碼** | 結果頁主視覺、16 張分享卡烤字 | V3 保留，且稱為「MBTI 代碼」 | **第二個風險所在** |
| **宣稱關聯** | 目前寫「不是官方 MBTI® 測驗」 | 未處理 | 屬指名合理使用，但若要拉距離應移除 |

補充：四字母分類屬於理論／系統，不受著作權保護，市面大量免費測驗長期使用；商標才是主要施力點。但若把四字母當成產品核心賣點，仍然是離 MBTI 最近的一條線。

### 2.2 Yves 規則本身的漏洞（以文件公布的權重實算）

文件只公布了 S／N 軸的完整權重（Q1 A=+0.70、B=−0.80；Q5 A=−1.00、B=+1.00，C 皆為 0）。把這一軸的 9 種作答全部算出來：

| Q1 | Q5 | 判定 | Balance | 顯示分數 |
|---|---|---|---|---|
| A | A | 務實 | −0.176 | 41 |
| A | B | 想像 | +1.000 | 100 |
| A | C | 想像 | +1.000 | **100** |
| B | A | 務實 | −1.000 | 0 |
| B | B | 想像 | +0.111 | 56 |
| B | C | 務實 | −1.000 | **0** |
| C | A | 務實 | −1.000 | **0** |
| C | B | 想像 | +1.000 | **100** |
| C | C | 無證據 | — | — |

由此看出五個漏洞：

1. **假精準。** 9 種組合有 6 種的顯示分數落在 0 或 100。只要兩題同向，不論權重是 0.70 還是 1.00，Balance 一律等於 ±1，因為分母也跟著變。每軸只有兩題時，「顯示分數」實際上只有五個可能值，卻長得像百分制。
2. **一鍵定終身，而且宣稱百分之百。** 粗體那四列是「選了一次 C」的情況：另一題的單一點擊不只決定了整條軸線，還回報 100% 的清晰度。這是最嚴重的漏洞。
3. **非對稱權重沒有發揮宣稱的作用。** 文件說非對稱能「減少完全歸零的機率」，但兩題同向時分子分母同步放大，權重差異完全被抵銷，只有兩題衝突時才有效。
4. **中性區門檻形同虛設。** 文件提議 |Balance| < 0.15 才顯示 X，但這一軸能達到的 |Balance| 只有 0.111、0.176、1.000 三種，9 種組合裡只有 1 種進得了中性區。兩題制的解析度根本撐不起這個門檻。
5. **全選 C 無法判定。** 四軸都沒有證據。現行程式會退回「探索者／證據蒐集中」，不會崩潰，但需要正式文案。

另有三處文件本身的缺漏，**必須請 Yves 補齊才能實作**：

- **完整權重表不存在。** 24 個選項只公布了 Q1、Q5 的完整權重，其餘只能從驗算範例反推。
- **驗算範例標錯選項。** Q2 寫「選擇 B『逐項查證』」，但 B 是「數據是死的，人是活的」（F 偏向），描述的其實是 A；Q7 寫「選擇 B『找同伴交換測試』」，B 是「做自己的神筆記」（I 偏向），描述的也是 A。兩處都用了 A 的權重，所以結論 ENTP 仍然正確，但照著範例接線會接錯。
- **六項能力沒有任何數字。** 文件說 C 選項會扣主動性與驗證能力，但沒有給每個選項的能力權重、量尺或呈現規則，這一塊目前無法實作。

### 2.3 採用 V3 題庫的工程風險

1. **C 選項對字母不給訊號 → 單點決定整條軸線。**
   V3 的 C 多為「退避／依賴」，只扣能力分、不給字母訊號。後果：玩家若 Q1 選 C、Q5 選 A，整條 S/N 軸就由那一個點擊決定。**現行測試「每軸兩題，不讓任何字母吊在單一點擊上」會直接擋下這個設計。**
2. **全選 C → 四軸皆無證據 → 代碼 XXXX。**
   目前有優雅退路（顯示「探索者／證據蒐集中」），不會崩潰，但需要為這個狀態設計正式文案與後續引導。
3. **括號註解會洩題。** 例如「（N偏向：先從小實驗與可能性切入）」是設計註記，玩家看到等於看到答案，上線前必須移除。
4. **職場框架排除部分受眾。** V3 假設有老闆、客戶、團隊、期限。大會若有學生、自由工作者、非上班族，會答不下去。
5. **選項變長，壓迫手機首屏。** 上週剛做完的「三個選項等高、首屏可見」在 375px 會被 V3 的長文案挑戰，需重新驗證。
6. **16 型文案會退步。** V3 的型別描述是顧問式短句；現行文案是刻意改寫的第二人稱大白話，且有測試把關長度與語氣。建議**只採用 V3 的題目，保留現行型別文案**。
7. **平衡與信度模擬需重跑。** 現行門檻：每個字母占所有答卷 40–60%、16 型全部可達且無單型超過 10%、J/P 輕微不一致者仍正確標記 ≥72%。V3 的新權重不保證通過，需實測後微調。

### 2.4 已被現有設計擋掉的風險

- 舊玩家重新計分 → 題庫版本分流已處理
- 部署風險 → staging 與正式環境分離，團隊回報小標籤只在測試環境

## 3. 需要決策：四字母的去留

這是整份計劃的分歧點，兩條路的成本差很多。

| | **方案一：降階（建議）** | **方案二：完全移除** |
|---|---|---|
| 做法 | 動物為主視覺，四字母縮小為輔助資訊 | 結果只有動物，四字母完全不出現 |
| 智財距離 | 中 | 高 |
| 16 張分享卡 | 不用重做 | **全部重製**（字母烤在圖裡） |
| 結果頁 | 改版面配置 | 改版面配置 |
| 內部命名 | 建議一併中性化 | 必須中性化 |
| 額外成本 | 0.5 天 | 0.5 天 + 設計重製 16 張 |
| 對 Brian 回報的解法 | 加一行白話解釋 | 問題自然消失 |
| 風險 | 仍保留最接近 MBTI 的元素 | 玩家失去可分享的「標籤感」，社群傳播力可能下降 |

**2026-09-19 最終定案：四字母保留（小尺寸），分享卡仍整批重做，但理由改變。**

時間軸：威廷原本拍板走方案二（完全移除）；同日 YVES 哥回覆「四個英文字可以放，不要特別大就是，我已經把它改成別的定義，所以只要不出現 MBTI 就沒問題。放著大家比較看得懂」。以總策劃的決定為準，因此：

- 四字母以**小尺寸、次要位置**回到結果頁與 LINE 結果卡（動物與稱號仍是主識別）。
- **「MBTI」字樣永不出現**，這條不變；內部命名、API 欄位、圖片網址也維持自有詞彙。
- 分享卡仍然整批重做，但原因從「拿掉字母」改為「調整版面 + 解決頭貼」。
- 殘留風險：字母被宣稱已重新定義，但重新定義的內容目前只存在於 YVES 哥那邊。我們的頁面用自己的四軸白話說明支撐它（能量來源／接收資訊／做決定／行動方式，八個極各一句）。若日後被問到字母代表什麼，答案必須指向這套說明，不能指向別人的量表。

原始拍板紀錄：

我原本建議方案一，理由是四字母是玩家願意分享的主要動機（「我是 ENTP」比「我是烏鴉」更容易被辨認），完全移除會犧牲傳播力。威廷決定承擔重製成本以取得最大智財距離，因此：

- D 軌從選用改為**必做**。
- 需補一項設計工作：**動物名必須扛起原本四字母的辨識度**。分享卡的主標與副標要重新設計，讓「烏鴉・創意破框者」本身就是可以拿出去講的身分，否則傳播力會實質下降。
