# AI 人格誌｜智財距離與 V3 題庫升級 產品計劃

日期：2026-09-19　｜　來源：YVES 哥（協會總策劃）提供之《分享 AI人格誌 v3》（09/15 V3）
狀態：待威廷與協會決策

---

## 0. 一句話結論

**技術上完全可行，但換題庫本身不會降低 MBTI 智財風險。**

V3 的題目是原創的，我們現行的題目也是原創的，兩者都沒有抄襲 MBTI 題項，所以「換題」這個動作不影響著作權風險。真正的風險在**商標字樣**與**把四字母當成產品主identity**，而 V3 文件不但保留四字母，還在規格裡直接寫「四組人格偏好（MBTI 代碼）」，等於把關聯寫進文件。

YVES 哥的方向是對的（降低對 MBTI 的依賴），但他選的槓桿（重寫題目）不是能移動風險的那一根。真正有效的是下面的 A 軌。

> 本文件不是法律意見。四字母是否保留、免責文案怎麼寫，建議由協會法務最終確認。

## 2. 風險盤點

### 2.1 智財風險的真實位置

| 風險來源 | 現況 | 換成 V3 後 | 評估 |
|---|---|---|---|
| **題項著作權** | 題目為本專案原創 | V3 也是原創 | 本來就無風險，換題不改變 |
| **MBTI® 商標** | 3 處使用者可見文字出現「MBTI®」 | V3 沒處理 | **實際風險所在** |
| **四字母代碼** | 結果頁主視覺、16 張分享卡烤字 | V3 保留，且稱為「MBTI 代碼」 | **第二個風險所在** |
| **宣稱關聯** | 目前寫「不是官方 MBTI® 測驗」 | 未處理 | 屬指名合理使用，但若要拉距離應移除 |

補充：四字母分類屬於理論／系統，不受著作權保護，市面大量免費測驗長期使用；商標才是主要施力點。但若把四字母當成產品核心賣點，仍然是離 MBTI 最近的一條線。

### 2.2 採用 V3 題庫的工程風險

1. **C 選項對字母不給訊號 → 單點決定整條軸線。**
   V3 的 C 多為「退避／依賴」，只扣能力分、不給字母訊號。後果：玩家若 Q1 選 C、Q5 選 A，整條 S/N 軸就由那一個點擊決定。**現行測試「每軸兩題，不讓任何字母吊在單一點擊上」會直接擋下這個設計。**
2. **全選 C → 四軸皆無證據 → 代碼 XXXX。**
   目前有優雅退路（顯示「探索者／證據蒐集中」），不會崩潰，但需要為這個狀態設計正式文案與後續引導。
3. **括號註解會洩題。** 例如「（N偏向：先從小實驗與可能性切入）」是設計註記，玩家看到等於看到答案，上線前必須移除。
4. **職場框架排除部分受眾。** V3 假設有老闆、客戶、團隊、期限。大會若有學生、自由工作者、非上班族，會答不下去。
5. **選項變長，壓迫手機首屏。** 上週剛做完的「三個選項等高、首屏可見」在 375px 會被 V3 的長文案挑戰，需重新驗證。
6. **16 型文案會退步。** V3 的型別描述是顧問式短句；現行文案是刻意改寫的第二人稱大白話，且有測試把關長度與語氣。建議**只採用 V3 的題目，保留現行型別文案**。
7. **平衡與信度模擬需重跑。** 現行門檻：每個字母占所有答卷 40–60%、16 型全部可達且無單型超過 10%、J/P 輕微不一致者仍正確標記 ≥72%。V3 的新權重不保證通過，需實測後微調。

### 2.3 已被現有設計擋掉的風險

- 舊玩家重新計分 → 題庫版本分流已處理
- 部署風險 → staging 與正式環境分離，團隊回報小標籤只在測試環境

## 3. 需要決策：四字母的去留

這是整份計劃的分歧點，兩條路的成本差很多。

| | **方案一：降階（建議）** | **方案二：完全移除** |
|---|---|---|
| 做法 | 動物為主視覺，四字母縮小為輔助資訊 | 結果只有動物，四字母完全不出現 |
| 智財距離 | 中 | 高 |
| 16 張分享卡 | 不用重做 | **全部重製**（字母烤在圖裡） |
| 結果頁 | 改版面配置 | 改版面配置 |
| 內部命名 | 建議一併中性化 | 必須中性化 |
| 額外成本 | 0.5 天 | 0.5 天 + 設計重製 16 張 |
| 對 Brian 回報的解法 | 加一行白話解釋 | 問題自然消失 |
| 風險 | 仍保留最接近 MBTI 的元素 | 玩家失去可分享的「標籤感」，社群傳播力可能下降 |

**2026-09-19 威廷拍板：走方案二，整批圖重做。**

我原本建議方案一，理由是四字母是玩家願意分享的主要動機（「我是 ENTP」比「我是烏鴉」更容易被辨認），完全移除會犧牲傳播力。威廷決定承擔重製成本以取得最大智財距離，因此：

- D 軌從選用改為**必做**。
- 需補一項設計工作：**動物名必須扛起原本四字母的辨識度**。分享卡的主標與副標要重新設計，讓「烏鴉・創意破框者」本身就是可以拿出去講的身分，否則傳播力會實質下降。

## 4. 工作計劃

### C 軌：六項 AI 時代能力（1.5–2 天）— 真正的差異化

這是 V3 文件裡最有價值、但目前完全沒實作的部分。程式裡六項能力的型別早就定義好，名稱與文件一字不差，**但現行八題沒有餵任何能力權重進去，第二份成績單是空的**。

| # | 任務 | 說明 |
|---|---|---|
| C1 | 替每個選項補能力權重 | 尤其 C 選項扣主動性與驗證能力 |
| C2 | 結果頁新增能力區塊 | 設計呈現方式（長條／雷達／文字） |
| C3 | 決定分享卡是否露出 | 影響設計成本 |
| C4 | 測試 | 能力分佈模擬與護欄 |

**策略意義：六項能力完全是我們自己的東西，與 MBTI 無關。把它做成結果頁的主角，是最徹底、也最正面的智財解法——不是迴避別人的東西，而是端出自己的東西。**
